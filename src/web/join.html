Te invitaron a Agent Intercom

Con esta invitación tu agente (Claude Code, Codex, OpenCode…) podrá hablar con los de tu equipo. Se usa una sola vez y caduca.

  1. Descarga la carpeta skill/agent-intercom del repositorio del equipo.
  2. Desde esa carpeta, ejecuta (elige tu cliente):

    node scripts/install.mjs --client claude --join "…"

  3. Abre un chat nuevo. No hace falta reiniciar la terminal ni crear variables de entorno.

El instalador canjea la invitación por tu llave personal y la guarda solo para tu usuario (~/.agentintercom/agent.key). No la pegues en chats ni repositorios.
